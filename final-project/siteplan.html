Speak Up with Chris

Individual Project Site Plan — WDD 231

1. Site Name

Name: Speak Up with Chris

Reason: This name clearly communicates the site's primary objective: encouraging non-native English speakers to build speaking confidence, gain fluency, and engage in interactive language tutoring with Christensen.

Optional Domain: speakupwithchris.com

2. Site Purpose

The purpose of Speak Up with Chris is to serve as a comprehensive educational and booking portal for English language learners. The site provides:

  • Information about specialized tutoring paths (Technical & Business English, Conversational Fluency).
  • Mentor profiles for Christensen and Maria highlighting their expertise and preferred audiences.
  • An online booking form for prospective students to request individual or group lessons.
  • An interactive, dynamic learning component (vocabulary and idiom references) fetched dynamically via API/JSON.

3. Target Audience Scenarios

The target audience includes IT professionals, engineering students, teenagers, and adult language learners looking to improve their career or everyday English skills.

  • Scenario 1: "I am a software developer preparing for a technical job interview in English. Which mentor and lesson focus best fit my needs?"
  • Scenario 2: "How do I book an individual tutoring session or contact the team regarding lesson pricing and schedules?"
  • Scenario 3: "Where can I find free interactive vocabulary cards or grammar tips on the site to practice on my own?"

4. Color Scheme

The site uses a clean, professional palette suited for an educational platform:

  • Primary Color (Teal / Turquoise - #008080): Used for main headings, border accents, primary buttons, and link highlights.
  • Secondary Color (Slate Gray / Navy - #2F4F4F): Used for header/footer backgrounds, container borders, and structural branding elements.
  • Background Color (Off-White - #F8F9FA): Provides a clean, low-glare background for high text contrast.
  • Text Color (Charcoal - #333333): Ensures readable body text across all screens.

5. Typography

Two complementary Google Fonts are imported and applied:

  • Heading Font: 'Montserrat', sans-serif
    Used for all <h1>, <h2>, and <h3> elements to deliver bold, clean, and modern titles.
  • Body Font: 'Open Sans', sans-serif
    Used for body text, paragraphs, lists, forms, and navigation links to ensure readability across all devices.

6. Home Page Wireframes

Structural layouts for the landing page across small (mobile) and large (desktop) viewports:

Mobile View (320px - 768px)

  • Header: Logo + Hamburger Menu button
  • Hero Section: Banner Image + "Book Now" CTA
  • Newsletter: Single-column subscription form
  • Features / Dynamic Content: Stacked single-column cards
  • Footer: Copyright, Social Icons, Last Modified

Desktop View (769px+)

  • Header: Logo + Horizontal Navigation Bar
  • Hero Section: Full-width Banner + Overlay CTA
  • Newsletter: Centered multi-field form
  • Features / Dynamic Content: 3-Column Grid layout
  • Footer: Centered links, Social Icons, Last Modified
